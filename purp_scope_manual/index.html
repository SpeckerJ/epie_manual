Manual Purpose

Purpose and scope of the manual

This practical manual outlines the functionalities of the ePiE model. ePiE stands for exposure to Pharmaceuticals in the Environment. The ePiE model predicts environmental concentrations (PECs) of active pharmaceutical ingredients (API) for human use in surface waters (i.e., rivers and lakes) across Europe based on per capita consumption data of APIs. It is available as a web application (https://shoeks.github.io/ePiE_webApp/), as a desktop application (https://shoeks.github.io/ePiE_desktopApp/), as well as a standalone R package (https://github.com/SHoeks/ePiE). This manual focuses on the web application, similar in its usage as the desktop application, and the R package. The manual is separated into 5 sections:

  1. Background information on APIs in the aquatic environment and exposure modelling
  2. How to use the ePiE web application
  3. How to use the EPiE R package
  4. Specific use examples
  5. Model interpretation and limitations

User interested in the technical details of the model are referred to the technical manual of the first ePiE version, downloadable by the link below. Further technical information is provided in Oldenkamp et al. (2018)1 on the first ePiE version and on Hoeks et al. (under review).
